## Ansible - Handler to restart Nginx

---
-name: Mangae nginx
hosts: all
become: yes

tasks:
   -name: Update config file
   copy:
    src: index.html
    dest: /usr/share/nginx/html/index.html
    notify: Restart nginx

hndlers: 
    -name:restart Nginx
    service: 
    name: nginx
    state: restarted

# Day 05- Environment variables
 you will learn hoe to ** use environment varibles in Jenkins Pipelines**

 Pipeline {
    agent any
    environment {
        INSTITUTE_NAME = "Pathnex"
        }
        stages {
            stage ('Print') {
                steps {
                    sh 'echo "Welcome to $INSTITUTE_NAME Devops Training" 
                }
            }
            stage ('Build') {
                steps {
                    sh 'mvn clean package - institute. name= $INSTITUTE_NAME'
                }
            }
        }
 }
